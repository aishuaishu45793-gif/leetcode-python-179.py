# Python Programming Practice

## About the Project

This repository contains Python programming practice programs designed to improve basic programming knowledge, logical thinking, and problem-solving skills.

The programs cover mathematical calculations, string operations, conditional statements, and basic Python concepts.

## Programs Included

### 1. Leap Year Checker

Checks whether a given year is a leap year or not using conditional statements and divisibility rules.

### 2. Average of Numbers

Accepts multiple numbers from the user and calculates their average.

### 3. Word Counter

Counts the total number of words in a sentence entered by the user.

### 4. GCD Calculator

Calculates the Greatest Common Divisor (GCD) of two numbers using Python's math module.

### 5. LCM Calculator

Calculates the Least Common Multiple (LCM) of two numbers using the GCD method.

## How to Run the Programs

1. Install Python on your computer.
2. Open the project folder in Visual Studio Code.
3. Open the Python file you want to execute.
4. Open the VS Code terminal.
5. Run the following command:

```bash
python filename.py
```

6. Enter the required input and view the output.
